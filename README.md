Plataforma web de **vagas de estágio** com foco em inclusão, acessibilidade e impacto social, com **recomendação de vagas por IA** e um **chatbot de carreira**. Projeto acadêmico (nov/2025) feito sozinho.


## 🏗️ Arquitetura
```
Front-end (HTML/CSS/JS) ──► API Node.js/Express ──► MongoDB
                                │
                                ├──► Serviço de IA (Python · Flask · scikit-learn)
                                └──► Google Gemini (chatbot)
```

## ✨ Funcionalidades
| Módulo | O que faz |
|---|---|
| 🔐 **Contas** | Cadastro/login com perfil de skills e experiência |
| 💼 **Conteúdo** | Vagas, cursos e artigos sobre carreira |
| 🧠 **Recomendação** | Microserviço Python ranqueia vagas por TF-IDF + similaridade de cosseno |
| 💬 **Chatbot** | Assistente de mercado de trabalho com Google Gemini |
| 📊 **Interações** | Registra visualizações e candidaturas |
